# EX No.5.1.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW
## DATE:16-11-2026

## AIM: 
To create orthographic view of given 3D model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
1. Open Autodesk Fusion 360 and create a new design by selecting File → New Design.

2. Select the Create Sketch tool and choose the required plane (XY, XZ, or YZ) to begin drawing the base profile.

4. Use the Line, Circle, Arc, and Rectangle tools to create the required 2D profile according to the given engineering drawing.
   <img width="51" height="51" alt="Screenshot 2026-11-16 015231" src="https://github.com/user-attachments/assets/675850a3-e0b2-45b0-878d-fc4c651f60c9" />

6. Apply the required dimensions using the Sketch Dimension (D) tool. Use Trim, Offset, and Constraints wherever necessary to complete the sketch accurately.
   <img width="70" height="57" alt="Screenshot 2026-11-16 014210" src="https://github.com/user-attachments/assets/00dea634-f89d-4498-a5ba-750344c7fa98" />

8. Convert the 2D sketch into a 3D model using the following tools:
- Extrude: To create the required thickness and height.
  <img width="50" height="57" alt="Screenshot 2026-11-16 192108" src="https://github.com/user-attachments/assets/65431c9f-ef16-4173-a005-ac9d114cc99b" />

- Hole: To create the required holes.
- Fillet: To round the sharp edges.
  <img width="58" height="51" alt="Screenshot 2026-11-16 191543" src="https://github.com/user-attachments/assets/55bd1ada-ed87-44c5-9773-cb17f4be7cb9" />

- Chamfer: To create bevelled edges.
  <img width="231" height="196" alt="Screenshot 2026-11-16 191633" src="https://github.com/user-attachments/assets/5adcabbd-9f17-4d6e-97b5-ea9753588f0e" />
  <img width="511" height="415" alt="Screenshot 2026-11-16 191647" src="https://github.com/user-attachments/assets/cf4c3ef7-c59a-43f7-a299-ede9188dd8e2" />


- Revolve: If a circular or rotational feature is required.
6. Use the Create Sketch, Extrude, and Hole tools wherever necessary to complete the remaining features of the component.

7. Check the completed 3D model using the Orbit, Pan, and Zoom tools to view it from different directions.

8. Switch from Design Workspace to Drawing Workspace by selecting Design → Drawing → From Design.
   <img width="1092" height="692" alt="Screenshot 2026-11-16 191810" src="https://github.com/user-attachments/assets/fd05b1e4-b34e-4a5a-a477-78c1833f98aa" />


10. In the Drawing Workspace, select the required drawing standard, sheet size, and orientation.

11. Select the Base View tool and place the model in the required position on the drawing sheet. Choose the front view as the base view and adjust the required scale.

12. Select the Projected View tool and click the base view to generate the required orthographic projections, such as top view, side view, and isometric view.

13. Position the projected views properly on the drawing sheet and click Finish to complete the orthographic drawing.

14. Save the completed design and drawing using the Save option.
